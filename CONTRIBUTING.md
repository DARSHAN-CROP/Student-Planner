# Contributing to Student Planner

Thanks for helping! This is a small personal project by Darshankumar Savsani (DARSHAN CORPORATION).

## Report a bug or suggest a feature
Open an issue with the template. Say which device/browser you use and what you expected to happen.

## Send a change
1. Fork the repo and make a branch (`feature/short-name`).
2. Keep one change per pull request.
3. Run the unit tests for the Android part (`./gradlew testDebugUnitTest`) and try the website in `docs/` in a browser.
4. Open a pull request and describe what changed and how you checked it.

Please write user-facing text in both Gujarati and English where the app already does.
